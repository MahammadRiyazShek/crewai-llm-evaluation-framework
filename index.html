🏗️ CrewAI Agent Architecture

📐 Relevance Agent

Checks if the response actually addresses the prompt's intent. Uses semantic similarity against the input question.

✅ Factual Accuracy Agent

Verifies factual claims against reference text and a knowledge base. Detects hallucinations.

🎯 Completeness Agent

Assesses whether the response covers all aspects of the prompt — no missing key information.

✍️ Clarity & Coherence Agent

Evaluates grammar, structure, logical flow, and readability of the response.

Agents collaborate through CrewAI's task orchestration. Each returns a 0–100 score on its rubric dimension, then a meta-agent aggregates verdicts into the final assessment.
